       Le message "limite API atteinte" était affiché pour TOUTE panne,
       d'où la fausse piste du quota.

       entre TOUS les visiteurs + bots scrutant GitHub (problème réel,
       mais pas la cause du symptôme observé)

       et le catch effaçait TOUT le cache au lieu des vieilles entrées

    4. Fallback OCM mort (clé vide) → aucun filet de sécurité

    - data/stations/{PROV}.json + data/regions/{PROV}.json servis statiquement
    - Zéro appel API tiers depuis le navigateur
    - Clé NREL retirée du client, lue via process.env dans les scripts
    - Cache localStorage supprimé (le cache HTTP suffit) + purge des vieux 'evca_'
    - CSP resserrée : developer.nrel.gov, openchargemap, statcan retirés
